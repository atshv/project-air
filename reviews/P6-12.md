## Verdict

Contract **0.5.0** adds optional plain-text `content` to checklist, columns and table blocks
(`block-content-payload.schema.json`, `kind` must equal the block `type`, palette/timeline carry
none), and the operations `updateBlockContent` and `updateZone`, each with an inverse of the same
type carrying the previous value. Both payloads have required fields, so they live in their own
schema files (`update-block-content-payload`, `update-zone-payload`) like `reorder-payload`; the
`contracts` gate classifies the bump as minor. Every schema `$id`, the root `contractVersion`, the
sync/API/gate fixtures and `board.contracts[]` (21 schema files, seven dependants) are at 0.5.0; TS
and C++ codegen are regenerated and the C++ parity harness compiles and agrees on all 119 fixtures.
