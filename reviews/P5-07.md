## Verdict

The `crdt-convergence` exit gate is green with honest, fail-closed evidence: 3 seeds × 10,000 =
30,000 rounds, encoded state **and** snapshot compared every round, zero divergences; two offline
**headless-Chrome pages** converge over the real sync service (equal hashes after reconnect and
after undo, wire logs committed); A's `undoOwn()` reverts only A's operation while B's edit stays.
The browser proof exposed a real **sync-service join-replay bug** (non-empty snapshots rebuilt the
CRDT from JSON content, so updates committed after the snapshot could lose the LWW race); it is fixed
by storing the encoded `docState` with the snapshot and replaying **all** updates after the snapshot
sequence, with a new real-PostgreSQL + Yjs regression test. The browser harness now exits non-zero on
failure, so the gate can no longer be green with `browser:false`. Lead re-ran the sync suite: 15/15.
