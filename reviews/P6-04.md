## Verdict

The board page now mounts the engine (WebGL2 default, fail-closed WebGPU choice), sizes the canvas
with ResizeObserver/DPR, loads board metadata through the SDK and uses **one SDK `BoardSyncClient`
whose real CRDT `BoardDoc` the SDK owns** (ADR-0012): snapshot/remote events project the board to
the engine via `loadRectangles`, local commits go through `sync.sendOperations`. The L00 toolbar has
36/20 px groups, one accent primary, active state and a **real 300 ms tooltip**, zoom +/−/fit work,
and L17 camera restore/save uses the engine view-persistence bridge; unmount disposes engine,
observer, save timer and socket. Round 1's fake structural BoardDoc and the missing tooltip were
fixed in round 2. Lead re-ran: SDK 30/30, web production build 412 kB JS / 127 kB gzip, scope clean;
no app-side document implementation remains.
