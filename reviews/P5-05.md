## Verdict

Presence uses the existing contract 0.3.0 message and stays ephemeral: the service validates it,
derives identity server-side (session user → `nameRef`/`colorRef`, client-sent values ignored),
throttles/coalesces per connection (50 ms budget), isolates per board, sends the participant list to
a newcomer and removes on leave/disconnect/close/shutdown — without persisting anything. The SDK
exposes throttled outbound presence and a participants subscription that clears on
leave/close/reconnect. A live-socket test floods 200 presence updates and still sees an
`operationBatch` ack, and proves identity, isolation and cleanup. Lead re-ran the suites: sync 13/13,
SDK 24/24.
