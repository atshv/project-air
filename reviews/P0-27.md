## Open questions

- **German masthead last-change translates the task title:** accepted. The line is UI text and the
  page language should be consistent; the task id `P0-27` keeps it traceable to `board.json`. The
  README should state that the title is translated in the DE locale (it currently says the title
  comes from `board.json` / the task brief and quotes only the English title).
- **1440 × 900 desktop shots cut the demo:** EN is acceptable (11 px of empty surface bottom), but
  the DE shot clips ~22 px of card B / the image window; recommend re-shooting DE (scrolled or
  1440 × 940). The committed 1426 × 583 / DPR 2 shot already proves the full DE demo and the owner
  viewport, so this is not a blocker.
- **18 identical DE/EN values:** intentional and correct. They are proper names, token/state labels
  and fixed values (`Block`, `Palette`, `Zone`, `REST API`, `Version`, `Link`, `Moodboard`, `Hover`,
  `Medium 500`, `Semibold 600`, `Demo: preview.js`, the date/time); "Hover" is the glossary term.
  No missing translation hides behind them.

## Merge concerns

- Do not merge as done until the English captions are translated; that is the A1 acceptance
  failure. The fix is small (one locale key per caption plus a `data-i18n` hook) and does not touch
  the switch, cache-busting or demo behaviour.
- The owner's stale-cache failure is really addressed for `preview.css`, `preview.js` and the
  locales: new HTML asks for URLs the browser has never cached, and the served bytes are current.
  Residual risk: an already-cached `index.html` may need one hard reload, `tokens.css`/icons remain
  unversioned, and the bump rule is manual; a future preview change that forgets `?v=` re-opens the
  class.
- The EN-file-blocked fallback inconsistency (finding 3) is unlikely in this static setup but is
  exactly the "missing locale file" edge case in the brief; fix it with the caption fix.
