# Architecture: packages/contracts

**Kind:** `package` · **Created in stage:** `contract`

## Purpose

The common language of the workspace: everything two packages exchange is defined here. Contract
`0.1.0` holds the board-content data model and its operations with exactly one inverse, as JSON
Schema with fixtures, generated TypeScript and C++ types, and a parity harness.

## Inputs

- JSON Schema sources under `schemas/`: one file per entity, the operation envelope and the root
  document.
- Valid and invalid fixtures under `fixtures/` in the `{schema, valid, reason, data}` wrapper.
- No runtime input from other workspace packages: the contract is dependency-free.

## Outputs

- Versioned schemas whose `$id` carries `0.1.0`; the root document binds `contractVersion` to it.
- `generated/types.ts` and `generated/contract.h`: committed, generated by `codegen.mjs` (Node
  builtins only), deterministic (sorted, LF, banner, no timestamps or absolute paths), with the
  entities, enums, operation payloads, discriminator and inverse pair.
- `index.mjs`: the contract version, the operation type vocabulary and the schema/fixture paths.
- A two-sided parity harness: a TypeScript canonical description of every fixture and a test-only C++
  program with its own JSON reader and the generated header; both must be identical.

## Invariants

- `AD-3` — The schemas are the single source; fixtures and both generated files change together and
  TypeScript and C++ read the fixtures identically (parity harness).
- `AD-1` — Every change is one operation with exactly one inverse; `group` bundles ordered children
  and reverses their inverses. `AD-4` — a note exists once and cards only reference it.
- Generated files are never edited by hand: `codegen` plus `git diff --exit-code` proves it.
- The header compiles with `-std=c++20 -Wall -Wextra -Wpedantic -Werror`; the parity program uses a
  self-written JSON reader and no third-party library.

## Allowed imports

None. `board.json` -> `packages[]` -> `may_import` is empty, so this package imports no other
workspace package. The tests use Node builtins and the local C++ compiler only.

## Commands

- `pnpm --filter ./packages/contracts run codegen` — regenerate the two generated files.
- `pnpm --filter ./packages/contracts test` — `node --test test/*.test.mjs`, including the C++
  parity harness; without an install `node --test packages/contracts/test/*.test.mjs` is equivalent.
- `pnpm --filter ./packages/contracts typecheck` — `tsc --noEmit` over the generated TypeScript types
  and the parity harness.
- `pnpm --filter ./packages/contracts lint` — ESLint.
