# P5-02 — CRDT document core behind an own interface (Yjs)

## Goal

`packages/crdt` provides a `BoardDoc` behind its own interface — `apply(op)`, `encodeUpdate()`,
`applyUpdate()`, `snapshot()`, `stateVector()` — backed by Yjs (MIT) with the contract operations
mapped inside the package, and proves convergence for 10,000 randomized operation rounds including
offline merges, snapshots and inverses.

**Why:** realtime needs one convergent document that both the sync service and the SDK can hold; Q4
and ADR-0011 decided Yjs behind an own, replaceable interface.

**Satisfies:** D11

## Scope

- `packages/crdt/` package skeleton: `package.json` with the scripts from `docs/module-map.md`
  (`lint`, `typecheck`, `test`, `build`), `tsconfig` extending the workspace base, README/ARCHITECTURE
  updated from "later" to the real module list and commands.
- `packages/crdt/` own interface: `BoardDoc` with `apply(op)`, `encodeUpdate()`, `applyUpdate()`,
  `snapshot()`, `stateVector()` plus the state/merge helpers the sync service needs (apply a remote
  update, apply a snapshot, compare final states); only own types are exported — no Yjs type or import
  appears outside the package.
- `packages/crdt/` Yjs adapter: map the contract board content (zones, blocks, note cards, notes,
  edges, zone parent references, fractional `z`) and every operation from
  `packages/contracts/generated/types.ts` to Yjs shared types; deletes are tombstones restorable by
  the operation's inverse; AD-4 note-once and AD-1 one-op-with-inverse are preserved; unknown or
  future fields are rejected safely.
- `packages/crdt/` conformance suite (adapter-independent): a seeded random operation generator over
  valid contract payloads produces 10,000 rounds applied in different orders on two replicas that
  must end in identical `encodeUpdate()`/`snapshot()`/state; offline batches merge; `snapshot()` →
  new replica → `applyUpdate()` reproduces the state; every operation followed by its inverse
  returns a byte-identical state.
- Dependency: pin Yjs in `docs/versions.md` with the exact version, licence (MIT) and the source
  (registry URL + date), add it to `packages/crdt/package.json` and the committed lockfile.
- `docs/adr/ADR-0011-crdt.md`: refine the consequences if implementation changes them (adapter
  boundary, snapshots, undo mapping); `.changes/P5-02-<short-name>.md` (area `engine`, kind `minor`).

## Out of scope

- The sync service and wire protocol (P5-03), SDK client/autosave (P5-04), presence (P5-05), undo UI
  (web-app), contract changes (P5-01), a second CRDT backend, persistence (the sync service owns
  PostgreSQL).

## Acceptance

A1 WHEN two BoardDoc replicas apply the same operations in different orders (including offline
batches), THEN they converge to the same encoded state and snapshot, and 10,000 randomized rounds run
without divergence.
A2 WHEN a contract operation is applied, THEN AD-1 holds (the operation and its inverse change one
element and restore a byte-identical state) and AD-4 holds (a note exists once, cards reference it);
unknown/future fields are rejected safely.
A3 WHEN the task is done, THEN `board-check`, `boundaries`, `unit` and `typecheck` exit 0 with
records, Yjs is pinned in `docs/versions.md` with its MIT licence and source, ADR-0011 records the
interface boundary, and no Yjs type leaks outside `packages/crdt`.

## Specifications

- Import rule: `packages/crdt` may import `packages/contracts` only (`boundaries` gate); the CRDT
  library lives behind the adapter, tests may import the generated types.
- The contract stays the wire format: updates/snapshots are opaque bytes/base64, never a second
  JSON schema of board content.
- Deterministic tests: a seeded PRNG, no clock or ambient randomness; 10,000 rounds must stay within
  a few seconds and bounded memory.
- A second adapter (a simple in-memory/fake implementation) must pass the same conformance suite, so
  the library stays replaceable (ADR-0011).
- Package commands follow `docs/module-map.md`; TypeScript only; no network in tests; no new
  dependency besides Yjs (owner-approved via Q4).

## Pitfalls

- A naive per-field mapping loses AD-1: the inverse must restore the exact previous state
  (including tombstones and zone parents), test it byte-identically.
- AD-4: a note exists once; two cards may reference the same note, but duplicating a note as a second
  document is a defect.
- Fractional `z` strings and zone parent references are order/identity sensitive; map them exactly.
- Random operations must be contract-valid (UUIDv7 ids, allowed enum values, sizes) or the test
  proves nothing.
- Snapshot encoding drift (one replica encodes to JSON, the other to binary) breaks convergence
  checks; fix one encoding and test a round trip.
- Pin Yjs with a source and date; an unpinned or unlicensed dependency fails review.
