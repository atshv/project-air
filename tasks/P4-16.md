# P4-16 — Multi-selection (L10)

## Goal

Several objects can be selected, moved and deleted together as one action: `Shift`-click adds and
removes, `Shift`-drag on empty space rubber-bands (a plain drag still pans), the frame is 1 px
`--accent` with an `--accent-soft` band, a count bar offers delete, a joint drag is exactly one group
operation with inverse, `Esc` clears, and the selection survives the drag. Selection is presentation
state, never document state.

**Why:** L10 is the prerequisite for zone moves (P4-27), resize of several objects and the later
keyboard actions.

**Satisfies:** D10

## Scope

- `packages/engine/` selection state in the input layer (P4-14): a preset of selected document slots
  kept outside the document and the operation payload; `Shift`-click toggles one object at a click
  below the 4 px threshold; a plain click replaces the selection; `Esc` clears it; selection is
  cleared on a document reload and never persisted.
- `packages/engine/` rubber band: `Shift`-drag on empty canvas draws a band and selects every live
  object whose bounds intersect it on release; without `Shift` the drag still pans (P4-14). The band
  is presentation-only.
- `packages/engine/` selection chrome in the chrome pass: one 1 px `tokens::accent` frame per selected
  object and a `tokens::accent_soft` fill with a 1 px `tokens::accent` border for the live band; at
  most the visible selected objects are framed; no new pipeline and no command-buffer instances, so
  object counts, hit tests and reference images stay unchanged.
- `packages/engine/` group drag: dragging a selected object moves every selected object by the same
  world delta and commits exactly one `drag-group` gesture through the P4-05 seam (`group` with
  inverse); dragging an unselected object first makes it the sole selection. The selection survives
  the release; a cancelled drag restores without an operation.
- `packages/engine/` count bar: DOM chrome (ADR-0009) above the selection bounding box showing
  "n selected" in the playground's demo-text convention plus a delete control (icon, no character or
  "×", `aria-label`); delete removes the selection in one operation with inverse; the bar follows
  the camera.
- `apps/engine-playground/`: sample and `?scene=layers` demonstrate Shift-click, rubber band, joint
  drag in one operation, the count bar and delete; a deterministic capture record under
  `reviews/evidence/` proves the frame, the band and the bar.
- Tests: TypeScript suite for add/remove/replace/Esc, band intersect rule, plain-drag-pans, one
  `drag-group` operation per joint drag, selection surviving the drag, unselected-drag selection,
  delete as one operation, cancel restore; `cpp-unit` regression. `.changes/P4-16-<short-name>.md`
  (area `engine`, kind `minor`); `docs/engine.md` documents selection state and chrome.

## Out of scope

  membership (P4-27), selection persistence across reloads, contract changes, new dependencies,

## Acceptance

A1 WHEN `Shift` is held and objects are clicked or a rubber band is dragged on empty space, THEN the
selection adds or removes objects, a drag without `Shift` still pans, the frame is 1 px `--accent`,
the band area `--accent-soft`, and `Esc` clears the selection; unit tests cover toggle, band
intersection, plain-drag pan and clear.
A2 WHEN several selected objects are dragged, THEN exactly one group operation with its inverse is
committed on release and the selection survives the drag; dragging an unselected object makes it the
selection first; a cancelled drag writes nothing. Unit tests and the playground confirm it.
A3 WHEN the task is done, THEN `board-check`, `boundaries`, `cpp-unit` and `unit` exit 0 with records
under `reviews/evidence/`, the count bar shows the selection with a working delete that writes one
operation, and `docs/engine.md` documents selection state, band rule and chrome.

## Specifications

- Values only from tokens: 1 px frame, `--accent`/`--accent-soft`, 4 px threshold, 120/150 ms motion;
  no raw values (design-check).
- Selection and band are presentation state; never in the document, operation payload or
  command-buffer counts.
- One gesture = one operation (AD-1): one `group` per joint drag, one delete; never a write per
  object.
- The band requires `Shift`; without it the drag pans. The rule is world-space intersection.
- No second pointer handler; the input layer owns selection and the band.

## Pitfalls

- Releasing the drag must not clear the selection; clear on empty click or `Esc` only.
- A band as command-buffer instances changes counts and drifts the `visual` gate; use the chrome pass.
- The count bar is DOM chrome placed from the camera transform; it must not jump while panning.
- Delete goes through the seam with an inverse (undo later), not a direct document remove.
- Rebuild bridge/WASM before the capture; run `board-check` before any `pnpm` command.
