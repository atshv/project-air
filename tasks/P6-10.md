# P6-10 — e2e suite: main flows and the e2e gate on the slot ports

## Goal

Playwright (Apache-2.0) config and the e2e suite run the app on the slot web ports with the slot
services: login → boards → create board → add/edit note and title → reload persists; two users edit
live, go offline/reconnect, both converge; toolbar/zoom/context menu/panel/L17 covered; the e2e gate
is documented and exclusive.

**Why:** the stage exit gate `e2e` and the blueprint P6-06 flow; the suite makes regressions visible.

**Satisfies:** D12

## Specifications

- Ports/DB only from `.polier-slot`: web-e2e 4101, platform 4310, auth 4320, sync 4330. No hardcoded ports.
- One worker; the suite starts/stops only its own processes (never `pkill`), seeds/resets its slot
  rows idempotently with fixed ids.
- Selectors: roles/accessible names first; `data-testid` only where roles cannot distinguish; no
  CSS-structure snapshots.
- Waits: web-first assertions, no arbitrary sleeps; offline/reconnect specs wait for L05 statuses.
- Wait for the engine-ready signal (or toolbar) before canvas interactions/first frame.
- Auth: gated test-mode session or seeded account — record it; never weaken the guard.
- Cleanup: close contexts, stop services, delete seeded rows; reruns pass.
- Flakiness is a defect: fix waits/fixtures, never retries.

## Pitfalls

- Two sessions/servers on the same slot corrupt the run; the e2e task is exclusive.
- The Vite preview serves the build, not the dev proxy — the preview needs the `/v1` and WebSocket
  proxies configured too (document the e2e serving choice).
- A canvas interaction before the WASM engine is ready silently does nothing; wait for ready.
- The offline spec must use `context.setOffline` on the page's context (not a global network switch).
- Seeded ids reused across runs collide; truncate/reset the seeded boards deterministically.
- Kratos/mail stays optional; CI does not depend on the identity profile.
- Pin and cache the Playwright browser; never rely on `latest`.

7. `e2e`: `pnpm exec playwright test` (exclusive; exact command in `docs/gates/playwright.md`) -> exit 0, all specs pass.
