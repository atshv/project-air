# P0-46 — Preview page: back-to-top arrow

> Static design preview (`apps/web/preview/`). Owner note (2026-10-27): the live preview is not
> bound to the usual brief budgets.

## Goal

Owner request of 2026-10-29: "baue auf der preview seite einen pfeilzeiger nach oben um immer zu
oberst anfangen zu können". The design-system page now has thirteen numbered sections plus the live
demo and is long. A reader who is deep in section 12 or 13 should get back to the start with one
click instead of scrolling.

1. **Button.** A round floating button with an upward arrow sits at the bottom right of the
   viewport, `--space-24` from both edges (`--space-16` below 768 px). It is 40 px
   (`--click-target` + `--space-8`; 44 px `--click-target-coarse` on touch), `--radius-pill`,
   `--surface` fill, a 1 px `--border` line and `--card-shadow`. The arrow is an inline 24-grid SVG
   drawn in `currentColor` with the icon stroke of the ui-kit set (1.6), at the 20 px bar icon size
   (`--icon-bar`), in `--fg`. Hover changes the border to `--border-strong` and the fill to `--faint`
   in `--motion-hover` (120 ms ease). Focus shows the standard `--accent` outline ring.
2. **When it shows.** It is hidden at the top of the page and fades in (opacity only, `--motion-fade`,
   150 ms) once the reader has scrolled more than one viewport height; it fades out again near the
   top. While hidden it is `visibility: hidden` and not reachable by Tab. It never covers the live
   demo's own chrome: it is page chrome on the `--layer-canvas-chrome` layer, fixed to the viewport,
   and sits outside the demo canvas.
3. **What it does.** Click, Enter or Space scrolls to the top of the page. The scroll is smooth
   unless `prefers-reduced-motion: reduce` is set, in which case it jumps. Afterwards focus moves to
   the page heading (the masthead `h1`, focusable with `tabindex="-1"`), so keyboard and screen-reader
   users also start at the top; the URL does not change.
4. **Text.** The accessible name and the tooltip come from the locale files: "Back to top" /
   "Nach oben" (du-form, `ss`, identical keys in `en.json` and `de.json`); it follows the DE/EN
   switch. It reads well in the dark and the light theme (P0-42) because it only uses tokens.
5. **Page bookkeeping.** Masthead "Last change" P0-46 with the change-file time, task list, asset
   `?v=P0-46`, a README section and the evidence list.

**Why:** the page is a reference the owner and the team scroll through often; returning to the top
and the page contents list (P0-45) should be one action.

**Satisfies:** D3

smooth scroll.
