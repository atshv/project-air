# P4-31 — English sample text in the engine playground (language-check)

## Goal

The engine playground's text demos use English sample content instead of German strings in code, so
`language-check` passes repo-wide again; umlauts and accents stay covered through names (Zürich,
Müller, café), and the affected `visual` references are re-captured and reviewed for both backends.

**Why:** `language-check` rejects German words in code (`docs/quality.md`, AGENTS rule "Code,
comments … in English; UI text only from translation files"). It reports ten findings in
`apps/engine-playground/main.js`, from the `?text=layout` demo (P4-09) and the `?text=titles`
gallery (P4-10). The owner asked on 2026-10-28 to clean them up.

**Satisfies:** D10

## Scope

- `apps/engine-playground/main.js`: every German sample string of the `?text=layout` runs and of the
  `?text=titles` gallery (titles and previews) becomes English sample content of similar length, so
  the layout cases stay the same: a title that fits, titles cut with an ellipsis, a wrapped preview
  clipped to its box with a hard line break, an empty preview, an em dash, Latin-1 letters (é, ü, Ü)
  inside names.
- `reviews/evidence/visual-baselines/`: re-capture `text-layout`, `text-titles` and
  `text-titles-zoom-200` for desktop and mobile on WebGL2 and WebGPU through the documented
  `--update` review path; every other reference stays byte-identical.
- `docs/engine.md` / `docs/gates/visual-diff.md`: only where they quote the old sample text.
- `.changes/P4-31-<short-name>.md` (area `engine`, kind `patch`).

## Out of scope

- Engine code, layout rules, glyph sets, other scenes, the preview (`apps/web/preview/` is clean),
  a translation system for the playground (it is a developer tool without a locale switch).

## Acceptance

A1 WHEN `node tools/language-check/index.mjs .` runs, THEN it reports no finding in
`apps/engine-playground/` and exits 0.
A2 WHEN the visual gate runs, THEN the re-captured `text-*` references show the same layout cases with
English content (fit, ellipsis, wrap with clip, empty preview, accented names) on both backends, and
every other reference passes unchanged.
A3 WHEN the task is done, THEN `board-check`, `language-check`, `visual` and `changelog-entry` exit 0
with records under `reviews/evidence/`.

## Context pack

**Read exactly:** `AGENTS.md`, `docs/quality.md` (language-check), `docs/gates/visual-diff.md`,
`apps/engine-playground/main.js` (text demos), `tools/language-check/`.

## Pitfalls

- Keep string lengths close to the old ones, or a cut title may suddenly fit.
- `check.py` scans `node_modules/`; run `board-check` before any `pnpm` command.
- The visual gate is exclusive; run it alone.

## Gates

1. `board-check`: `python3 $POLIER/tools/check.py .`
2. `language-check`: `node tools/language-check/index.mjs .`
3. `visual`: `node packages/engine/test/visual/run-visual.mjs --task P4-31`
4. `changelog-entry`: `node tools/release/check-changes.mjs --task P4-31 --base main`

## Limits

- **Scope:** only `apps/engine-playground/`, `reviews/evidence/visual-baselines/`, `docs/engine.md`, `docs/gates/visual-diff.md`, `.changes/`
- **Stop:** 2 rounds; when blocked, `status: blocked` + reason.
