# P0-35 — Design system page: contract 0.3.0, missing tokens and engine chrome

> Static design preview (`apps/web/preview/`). Owner note (2026-10-27): the live preview is not bound
> to the usual brief word or token budgets.

## Goal

The design-system page shows what the repository holds today. An audit on 2026-10-28 found:

1. **Outdated:** the contract overview still shows 0.1.0 (16 schema files, 19 operation types,
   77 parity fixtures). The contract is **0.3.0**: 17 schema files (11 board content incl. the
   `reorder` payload, 1 sync, 5 REST API), 20 operation types (new `reorder`), 86 parity fixtures
   (37 valid, 49 invalid), the containment corpus (0.2.0) and the pre-realtime sync rules (0.3.0).
2. **Missing:** 23 of 77 tokens are not on the page — the motion durations, the twelve layers
   (z-index order incl. 7a remote cursors), the interaction values (drag threshold, snap tolerance,
   coarse click target, outline offset) and the tooltip and pill radii.
3. **New, not shown:** the engine chrome of stage 5 — zone/block headers (40 px band in `--faint`,
   rule in `--border`, quiet delete button), the selection frame with eight 8 px handles, the
   rubber band, snap guides (max. 3), the one-second zone highlight in `--accent-line`, the count
   bar with delete, the undo hint in the bottom-centre slot and the context menu (200 px, 32 px
   rows, shortcuts in `--muted`).
4. **Gone:** nothing was removed from the system; only the 0.1.0 texts and counts go away.

**Why:** owner request: review the design-system page after the latest updates — what is missing,
new or gone.

**Satisfies:** D3
