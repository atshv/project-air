# P4-20 — Keyboard and context menu (L12)

## Goal

`Cmd/Ctrl+D` duplicates with a +16/+16 offset, `Del`/`Backspace` deletes, `Esc` closes panel or
selection, arrows move 16 px (`Shift` 160 px) as one operation 300 ms after the last key, and a 200 px
context menu with 32 px entries works by keyboard; shortcuts never act in a field.

**Why:** L12 — common actions must be reachable without a mouse, and the context menu must be operable
without one.

**Satisfies:** D10

## Scope

- `packages/engine/` keyboard intent layer: one module mapping keys to intents only outside fields
  (reuse P4-14 suppression for `input`, `textarea`, `select`, `[contenteditable]`, `[data-field]`):
  duplicate (`Cmd/Ctrl+D`), delete (`Del`/`Backspace`), nudge series (arrows 16 px, `Shift` 160 px,
  one `keyboard-nudge` 300 ms after the last key, preview without writing), `Esc` (priority: menu,
  overlay/field, selection) and menu open (right-click/`Shift+F10`/menu key).
- `packages/engine/` duplicate/delete through the P4-05 seam: duplicate copies the selection 16 px
  right/down as one create (or one group) with inverse; a note-card duplicate follows the contract
  note-once rule (document same-note vs copied-note group); delete reuses the selection delete;
  every action is exactly one operation.
- `packages/engine/` context menu as DOM chrome (ADR-0009): 200 px wide, 32 px entries "Open /
  Duplicate / Bring forward / Send backward / Delete" in the playground demo-text convention,
  shortcuts right-aligned in `tokens::muted`, tokens only; keyboard model (arrows, `Enter`/`Space`,
  `Esc`) and pointer model; never opens in a field; closes on outside click/`Esc`/blur/action; menu
  entries route to the same intents as the shortcuts.
- `apps/engine-playground/`: keyboard/menu demo on the layers scene, capture record + screenshots
  under `reviews/evidence/` (1440×900, 390×844); no reference image changes (menu opens on demand).
- Tests: routing (field focus blocks every shortcut, `Esc` priority, duplicate offset/one
  operation, delete one operation, nudge batching 300 ms and 16/160 px, no mixed series), menu model
  (open/close, arrow wrap, activation, outside click), design-check for the menu CSS.
  `.changes/P4-20-<short-name>.md` (area `engine`, kind `minor`); `docs/engine.md` documents the map,
  field rule, menu geometry and routing.

## Acceptance

A1 WHEN `Cmd/Ctrl+D`, `Del`/`Backspace` or an arrow series is pressed outside a field, THEN duplicate
lands +16/+16, delete removes the selection as one operation, and the arrow series moves 16 px
(160 px with `Shift`) as exactly one operation 300 ms after the last key; all three have inverses.
A2 WHEN `Esc` is pressed, THEN it closes the context menu first, then an open overlay/editing field,
then the selection, in that order.
A3 WHEN the context menu is opened by right-click or keyboard, THEN it is 200 px wide with 32 px
entries, reachable and operable by keyboard (arrows, `Enter`, `Esc`), closes on outside click, and
its shortcuts are right-aligned in the muted token; `design-check` passes.
A4 WHEN the task is done, THEN `board-check`, `boundaries`, `cpp-unit`, `unit` and `design-check`
exit 0 with records under `reviews/evidence/`, the playground demonstrates keyboard and menu actions,
and `docs/engine.md` documents the map, field rule, menu and routing.

## Specifications

- One keyboard intent layer, one routing table: shortcuts and menu entries call the same intents;
  no second action path.
- Field focus wins: no shortcut may act inside `input`/`textarea`/`select`/`[contenteditable]`/
  `[data-field]`; test every shortcut against a focused field.
- One gesture = one operation (AD-1): duplicate and delete are one operation (one group for a
  selection); an arrow series is one `keyboard-nudge`, not one per key.
- Values only from tokens for the menu (200 px width, 32 px rows are L12 interaction values
  documented as named constants; colours/spacing from tokens); no character or emoji as an icon, no
  native `title` tooltip.
- `Esc` priority is documented and tested; the menu never opens while a field is focused.
- No new token, dependency or contract change; a missing value becomes an open question.

## Pitfalls

- Key repeat can split an arrow series; accumulate, commit once, clear on other input.
- `Cmd/Ctrl+D` is a browser shortcut too; `preventDefault` only when the canvas owns it.
- A note-card duplicate must respect AD-4; document the contract path.
- The menu is DOM chrome; close or reposition it once, never jump on pan/zoom.
- Reuse the P4-14 field predicate (includes editable focus).
