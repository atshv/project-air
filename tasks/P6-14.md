# P6-14 — Engine for the app: contract 0.5.0 and the interaction exports

## Goal

The engine accepts contract 0.5.0 (block content for the required height, `updateZone` for renames
instead of the delete + create group) and exports the interaction modules the web app needs as a
stable, typed public surface, with a short guide on how an app wires them.

**Why:** owner decision 2026-10-29: the web app must behave like the live demo. The engine already
has the behaviour (P4-14…P4-30), but the app can only import `.`, `./logic/*` and
`./bridge/view-persistence.js`.

**Satisfies:** D12

## Scope

- `packages/engine/` contract 0.5.0: wasm version assertion, operations/document-port accept
  `updateBlockContent` and `updateZone` with inverses; the P4-30 zone rename now builds one
  `updateZone`; block required height can be computed from block content (checklist points,
  columns, table rows) through the existing binding path.
- `packages/engine/` public exports in `package.json`: input (L03), snapping (L07), selection
  (L10), resize (L14), auto-pan (L16), placement (L20), overlay (L18), zone-parity and
  zone-lifecycle (L08), text binding (L02), each with types and built into `dist/`.
- `docs/engine.md` "Using the engine from an app": what an app must wire (pointer events and
  capture, DOM overlay, motion settle, operation commit, rebinding text) based on how
  `apps/engine-playground/main.js` does it.
- The playground uses the new rename path; its captures stay green.
- `.changes/P6-14-<short-name>.md` (area `engine`, kind `minor`).

## Out of scope

- Depth-ordered text (P6-15); any `apps/web` change (P6-16 onward); edges, images, touch.

## Acceptance

A1 WHEN a zone is renamed or block content changes, THEN exactly one 0.5.0 operation with its
inverse is produced and the block height follows the content without an inner scrollbar.
A2 WHEN an app imports the listed modules by their package export, THEN `typecheck` resolves the
types and the import works from the built package (a small consumer test).
A3 WHEN the task is done, THEN the engine node tests, `cpp-unit`, `wasm-build`, `typecheck`,
`board-check` and `boundaries` exit 0 with records; the change entry exists.

## Specifications

- Exports are explicit subpaths, never a wildcard; internal helpers stay private.
- The rename path change is a real seam change with unit coverage; the old group path is removed.

## Pitfalls

- The wasm must be rebuilt after the contract bump or the version assertion fails at runtime.
- Exports pointing at `src/` instead of `dist/` break the app build.
