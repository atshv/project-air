# P0-27 — Bilingual preview with DE/EN switch and cache-busted assets

> **Size:** 400–900 words. UI task in the static design preview (`apps/web/preview/`).

## Goal

The whole design preview is available in **English and German** with a themed **DE/EN switch at the
top right**; every visible string comes from locale files, not from code. Preview assets are
cache-busted so a changed preview is never rendered with stale CSS/JS (the owner saw new markup with
old styles and a broken-looking demo).

**Why:** bilingual preview; the stale-cache rendering was a real failure, so versioned assets and
a reload rule are part of the fix.

**Satisfies:** D3

## Scope

- `apps/web/preview/locales/en.json` and `de.json` — every visible string (masthead, section
  eyebrows/headings/intros, demo hints/legend/status/labels and zone content, token/component
  captions, sample-board labels, footer, `aria-label`/`alt`/`title`); keys lowerCamelCase per
  section, **identical key sets** in en/de.
- `apps/web/preview/index.html` — English defaults as no-JS fallback with `data-i18n="<key>"` (and
  `data-i18n-attr` for `aria-label`/`alt`/`title`); CSS/JS links gain `?v=P0-27`; masthead last
  change `P0-27 — Bilingual preview with DE/EN switch and cache-busted assets` + `.changes` mtime,
  Tasks + P0-27, version unchanged.
- `apps/web/preview/preview.js` — locale controller: fetch `locales/<lang>.json` (HTTP, no build),
  apply texts/attributes, set `<html lang>`, update `aria-pressed`, persist `preview-locale`
  (default `en`), English fallback on fetch failure.
- Top-right switch in the masthead meta area: compact segmented `DE │ EN`, token colours/borders,
  ≥32 px targets, keyboard reachable, translated `aria-label`; fits at 390 px without overflow.
- `apps/web/preview/README.md` — switch, locale/key parity, HTTP-serving note, cache-bust rule
  (bump `?v=` on every preview change), screenshots.
- `.changes/P0-27-bilingual-preview.md` (area `web`, kind `minor`).
- Evidence: `P0-27-desktop-{en,de}.png` (1440×900), `P0-27-mobile-{en,de}.png` (390×844),
  `P0-27-preview.log` (commands/statuses/sizes/asset-version check), optionally
  `P0-27-1426x583-de.png` (DPR 2) proving fresh CSS renders correctly at the owner's viewport.

## Out of scope

- The zone detach interaction (P0-28), product i18n (`apps/web/messages/`, language-check key rules
  stay untouched), new tokens/icons, new dependencies, a translation build step, translating the
  shell in `apps/engine-playground/`.

## Acceptance

A1 WHEN the page is opened, THEN all visible text and translated attributes switch between English
and German via the top-right switch, no mixed-language leftovers remain, `<html lang>` changes,
the choice persists across reloads, and a missing locale file falls back to English.
A2 WHEN the locale files are compared, THEN en and de have identical key sets and the German copy is
du-form, calm, without exclamation marks and with `ss` (never `ß`), and no German string lives in
HTML/JS/CSS (language-check stays green).
A3 WHEN the page is reloaded after a preview change, THEN the versioned CSS/JS URLs load the current
files, the README documents the bump rule, and the demo interactions (cards, keyboard, edge, zoom,
toolbar) are unchanged.
A4 WHEN `board-check`, `design-check`, `language-check` and `changelog-entry` run, THEN all exit 0
with records committed; the screenshots and log are committed under `reviews/evidence/`; the masthead
shows P0-27 with the entry's date/time.

## UI specification

| Element | Property | Value | Token |
| --- | --- | --- | --- |
| Switch | height, radius, border | 32 px, pill, 1 px (`--click-target`, `--radius-pill`, `--border`) |
| Switch option | padding/target | 8 × 12 px / 32 px (`--space-8`, `--space-12`, `--click-target`) |
| Switch active | background/colour | `--accent-soft`, `--accent`; rest `--muted`, hover `--faint` |

**States:** options rest/hover/focus-visible/pressed/selected (`aria-pressed`); current language
selected.

**Do not:** raw colours; new tokens; off-grid spacing; numeric z-index outside `layers.ts`;
external fonts/CDNs; German strings in HTML/JS; demo-behaviour changes; build step/dependency.

**UI evidence:** serve the repository root on the slot's web port from `.polier-slot`; capture the
four named screenshots (plus the optional 1426×583 DE shot) with the local Chrome for Testing (CDP
device metrics for exact widths); write the log with exact commands, HTTP statuses/sizes and the
`?v=P0-27` check. Only your own server.

## Pitfalls

- `board-check` before any `pnpm` command; `design-check` rejects raw colours/off-grid spacing/
  numeric z-index; `language-check` rejects German in code and `ß`.
- JSON is not scanned by language-check — that is exactly why all German copy lives there; keep the
  keys identical in en/de.
- The `.changes` mtime is the masthead time: write the entry first, then stamp.
- Do not edit `CHANGELOG.md`, `STATUS.md`, `board.json`, `apps/web/messages/` or package manifests.
- A stale preview is the bug we are fixing: bump the `?v=` query in the same task and verify the
  served URLs in the log.

## Edge cases

- 390 px: switch fits/does not overlap the meta text or cause horizontal overflow.
- Missing/unreadable locale file → English fallback with no console error loop.
- `localStorage` unavailable → default English, switch still works for the session.
- Long German strings wrap without clipping the fixed-size pills/labels.
