# P6-19 — Zone arrangement and release preview on the web canvas (L08, part 1)

## Goal

Zones in `apps/web` arrange their members like the live demo (stacked or side by side), and
dragging shows the release preview: landing slot, room-making, shrinking frame when an item
leaves; items can be docked, undocked and reordered, and every settle uses the one calm 300 ms
ease-out. Each release commits one operation through the SDK.

**Why:** owner decisions 2026-10-27 ("the engine must work like the live demo") and 2026-10-29
(close the stage-7 gaps first). The engine has this since P4-29, but the app does not use it.

**Satisfies:** D12

## Scope

- `apps/web/` wire the engine zone-parity module into the P6-17 pointer layer: enter/stay/leave
  hysteresis, orientation and order from the engine, landing slot and frame outline in a DOM
  overlay (z-index from `layers.ts`), motion settle with reduced-motion support.
- Commit: arrangement, dock, undock and reorder each as the one engine-built operation or group
  through the existing commit path; one undo reverts each.
- Zone drag moves its members (P4-27 group move).
- Realtime: a remote member move while the local user drags updates the preview without breaking
  the gesture; the dragged member never jumps.
- Tests: pure tests for the app-side mapping; e2e for dock, undock, reorder and undo.
- Side-by-side screenshots app vs demo for dock preview and settled arrangement at 1440×900 and
  390×844 under `reviews/evidence/`.
- `.changes/P6-19-<short-name>.md` (area `web`, kind `minor`).

## Out of scope

- Grouping into a new zone, empty-zone removal, names, zone tool and delete (P6-20); image windows
  (hardening); nested zones; touch.

## Acceptance

A1 WHEN a card is dragged into, within or out of a zone, THEN the preview matches the demo (landing
slot, room-making, shrinking frame) and the release commits exactly one operation that one undo
reverts.
A2 WHEN a second client watches, THEN it sees the settled arrangement after the acknowledgement,
and a remote move during a local drag does not break the gesture.
A3 WHEN the task is done, THEN the screenshots are committed and `board-check`, `boundaries`,
`unit`, `typecheck`, `design-check`, `language-check` and `e2e` exit 0 with records; the change
entry exists.
