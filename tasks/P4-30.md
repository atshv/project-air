# P4-30 — Zone parity with the live demo II: lifecycle and names (L08)

> Owner decision (2026-10-27): "The engine must work the way the live demo shows it." Reference:
> `apps/web/preview/` (README "Zone interaction"/"Zone name", `preview.js` zone section), read-only;
> the engine port is `packages/engine/`, the demo code is never imported.

## Goal

Like the live demo, two free objects dropped onto each other form a new zone (dashed ghost frame
while it stays, contact within 32 px keeps it, one release operation creates the zone with both as
members and the default title "New zone"/"Neue Zone"); an emptied zone is removed as one undoable
operation (dashed dim frame while the last member leaves; the release removes zone, title and slot);
and every zone shows its contract `title` in the 40 px header (one line, ellipsis) with inline rename
through the P4-23 overlay — click selects all, `Enter`/blur commits, `Escape` restores, empty returns
to the default, 40 characters — and the header never stretches on resize. ADR-0010 is
amended.

**Why:** the demo must show the same lifecycle and names the design preview shows.

**Satisfies:** D10

## Scope

- `packages/engine/` grouping: a dashed ghost frame with the landing slot next to the object that
  is not moved (20 % overlap or 16 px pointer starts it, 32 px contact keeps it); the
  release creates the zone with both objects and the default title as one operation with inverse.
  If one object is the only member of an existing zone, that zone wraps both and keeps its title.
- `packages/engine/` emptied zone: the frame turns dashed and dims while the last member leaves
  (presentation only); the release removes the zone as one undoable operation (title, slot and
  members restored by the inverse).
- `packages/engine/` names: the contract `title` renders in the 40 px header (one line, ellipsis at
  the token title role, P4-10/P4-27 geometry); inline rename through the P4-23 overlay (select all,
  `Enter`/blur commits, `Escape` restores, whitespace collapsed, empty → default, max 40 characters)
  stores the title via the contract seam as one operation; the header is not a child of the
  FLIP-scaled frame, so it never stretches.
- `packages/engine/test/visual/run-visual.mjs` + `docs/gates/visual-diff.md`: deterministic
  lifecycle/name scenes with reviewed baselines (reference set and Baseline history extended here;
  every existing image stays 0-diff).
- `apps/engine-playground/`: demo of grouping, emptied-zone removal and rename with a deterministic
  capture record and screenshots against the demo under `reviews/evidence/` (1440×900 and 390×844).
- Tests: grouping thresholds and one-operation creation with inverse, existing-zone wrap without
  rename, emptied-zone removal with inverse, title commit/restore/default/length, header not scaling
  during resize, cancel restore, language defaults. `.changes/P4-30-<short-name>.md` (area `engine`,
  kind `minor`); `docs/engine.md` documents lifecycle and names; `docs/adr/ADR-0010-zone-containers.md`
  records the approved amendments (emptied zones are removed; grouping creates a zone; the contract's
  `group` covers the creation).

## Out of scope

as one undoable operation with the same preview as the live demo; native tests cover both.
A2 WHEN a zone title is edited, THEN the live demo's rename rules hold and the title is stored
through the contract; a new zone carries the default title.
A3 WHEN the task is done, THEN ADR-0010 is amended, playground screenshots match the demo, the
reviewed `visual` references exist, and `board-check`, `boundaries`, `cpp-unit`, `visual` and
`typecheck` pass with records while every previously committed image stays 0-diff.

## Specifications

- Values only from tokens: 40 px header, title role, 16/12 px spacing, 20/16/32 px grouping
  thresholds, 40-character limit; no raw values (design-check).
- Grouping, empty-zone removal and rename each commit one operation with inverse (AD-1); frames and
  the rename field are presentation state.
- The title is contract state (0.2.0 `zone.title`): one write path, no second copy.
- Default titles follow the playground language; translated product defaults are web-app work.
- `visual` is exclusive: never run it next to another browser gate.

## Pitfalls

- Remove the zone only after capturing title, slot and members, or the inverse is lost.
- A group that silently becomes a rename on a one-item zone: test the wrap path separately.
- Scaled header text is visible in a screenshot; assert its final size during a resize.
- New baselines only through the reviewed `--update` path.
