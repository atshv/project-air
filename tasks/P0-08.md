# P0-08 — CI skeleton

## Goal

A GitHub Actions workflow exists that runs the board check, boundaries, install, lint, typecheck,
tests, design-check, language-check and the change-entry gate on every pull request; it is authored
and proven locally now (actionlint + act), while the real GitHub run waits for the remote stage.

**Why:** every later gate plugs into this pipeline; proving it locally now avoids a broken workflow
at the GitHub switch (ADR-0003).

**Satisfies:** D6

## Scope

- `.github/workflows/ci.yml` only:
  - trigger: `pull_request` to `main` and `workflow_dispatch`; `permissions: contents: read`;
    one job on `ubuntu-24.04` with a timeout;
  - steps: checkout; Node from `.nvmrc` (`actions/setup-node`); pnpm `12.14.0`
    (`pnpm/action-setup`); clone Polier `v1.0.0` into `$RUNNER_TEMP/polier` and export `POLIER`;
  - **board-check before install** (`python3 "$POLIER/tools/check.py" .`) because `check.py` scans
    `node_modules/`;
  - `pnpm install --frozen-lockfile`, then `pnpm lint`, `pnpm typecheck`, `pnpm test`;
  - `python3 "$POLIER/tools/boundaries.py" .`;
  - `node tools/design-check/index.mjs .` and `node tools/language-check/index.mjs .`;
  - change-entry gate for task branches only: derive `TASK=${GITHUB_HEAD_REF#task/}` and run
    `node tools/release/check-changes.mjs --task "$TASK" --base "origin/${{ github.base_ref }}"`
    (checkout with enough history, fetch the base ref); skip on non-task branches with a clear
    condition.
  - No secrets, no write permissions, no deploy; pinned tool versions only.
- Local proof: workflow lint with the `rhysd/actionlint` Docker image and a local `nektos/act`
  listing/run via Docker (no host installs); save the outputs in the manual evidence log.
- Report the exact workflow-lint command for the new `ci-local` gate; the lead records it in
  `docs/quality.md`.

## Out of scope

- Branch protection (P0-02), real GitHub runs (`ci-green`), the pinned-Polier wrapper
  (`tools/polier.sh`, P0-09), releases and deploys (P0-15/16/17, remote stage).
- Any change outside `.github/workflows/ci.yml`.

## Acceptance

A1 WHEN the workflow is read, THEN it runs on pull requests and contains the ordered steps above,
with board-check before `pnpm install`, and no secrets or write permissions.
A2 WHEN the workflow is linted with actionlint (Docker) locally, THEN it exits 0 with no findings;
the exact command and output are in the evidence log.
A3 WHEN act is asked to list (or dry-run) the workflow locally, THEN the job and its steps are
recognised; if act is not practical, the evidence log records the attempt and actionlint plus a
local run of every step's command stands in.
A4 WHEN the `board-check` and `ci-local` gates run through `gate.py`, THEN both exit 0 with
committed records; `python3 $POLIER/tools/check.py .` exits 0 (before `pnpm install`).

## Context pack

**Read exactly:**

- `ARCHITECTURE.md`, `AGENTS.md`, `STATUS.md`, `docs/module-map.md`, `docs/quality.md`
- `docs/gates/node-ts.md`
- `package.json`, `.nvmrc`, `.npmrc`, `pnpm-lock.yaml` (versions only)
- `docs/adr/ADR-0003-remote-phase.md`

**Do not read:** other briefs, `reference/`, `docs/owner/`, other packages.

**Budget:** ≤ 20k tokens input.

## Specifications

- **Runtime images:** `rhysd/actionlint:latest` and `nektos/act:latest` are pulled via Docker for
  the local proof; nothing is installed on the host. Docker Desktop is the local runtime.
- **Version sources:** Node from `.nvmrc` (`24.22.1`), pnpm `12.14.0`, Polier tag `v1.0.0` from
  `board.json` → `generator_version`; do not hard-code a different version.
- **Base branch:** `main` (from `board.json`); the workflow uses `github.base_ref`.
- **Change gate:** code paths are enforced by the tool; the workflow only supplies the task id and
  base ref. A branch without a `task/<ID>` prefix skips the change gate.
- **Local proof:** actionlint must lint the file; act must at least list the job/steps. Prefer a
  real act run of the job if the images are available; record what was actually run.
- **Evidence:** `reviews/evidence/P0-08-ci-local.log` plus the gate records.

## Pitfalls

- `check.py` scans `node_modules/`; keep board-check before the install step.
- `pnpm install --frozen-lockfile` needs the committed lockfile; no dependency changes here.
- The checkout action must fetch enough history for `git diff --base`; use `fetch-depth: 0` or
  fetch the base ref explicitly.
- Do not use floating `pnpm`/Node versions; pin exactly.
- Some `act` images need the Docker socket; mount it read-write only for the local proof and stop
  afterwards. Never start long-running containers.
- No `continue-on-error` and no `|| true` to hide failures.

## Edge cases

- `workflow_dispatch` has no base ref: skip the change-entry step with a clear condition.
- A fork PR has no secrets and read-only token: the workflow must still run.
- `act` cannot reach the network for the Polier clone in some setups: record the limitation; the
  real GitHub run happens in the remote phase.

## Gates

1. `board-check`: `python3 $POLIER/tools/check.py .` → exit 0 (before `pnpm install`).
2. `ci-local`: the actionlint Docker command chosen here → exit 0, no findings; the act listing/run
   is recorded in the evidence log.

## Limits

- **Scope:** only `.github/workflows/ci.yml`; gate records and the manual log under reviews/evidence
  are always allowed.
- **Stop:** 2 rounds; when blocked, `status: blocked` + reason.
