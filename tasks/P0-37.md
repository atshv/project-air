# P0-37 — Live demo: engine canvas chrome

> Static design preview (`apps/web/preview/`). Placeholder brief; refined when P0-36 is done.
> Owner note (2026-10-27): the live preview is not bound to the usual brief budgets.

## Goal

The live demo uses the stage-5 engine chrome that the design-system page shows in section 10, with
the same tokens and rules as `docs/engine.md`:

1. **Rubber band** — Shift-drag on the empty canvas draws a `--accent-soft` fill with a 1 px
   `--accent` border; on release every touched object is selected (L10).
2. **Snap guides** — while dragging, edges and centres within 6 screen px (`--snap-tolerance`) snap
   and up to three 1 px accent guides show, 16 px past both objects; Shift moves freely (L07).
3. **Zone drop highlight** — a member dropped into a zone outlines the zone in `--accent-line` for
   one second (L08).
4. **Undo hint** — `Cmd/Ctrl+Z` undoes the last move, resize or dock in the demo and shows
   "Undo: …" for 3 s in the bottom-centre slot (L11, design law §9).
5. **Context menu** — right-click, `Shift+F10` or the menu key on an object: Open, Duplicate (⌘D),
   Bring forward, Send backward, Delete (Del); 200 px wide, 32 px rows (L12).
6. **Header delete and count bar** — the zone header's delete button appears on hover, focus or
   selection; a multi-selection shows the "n selected" count bar with a delete button (L02, L10).
