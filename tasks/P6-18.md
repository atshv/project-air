# P6-18 — Multi-select and resize on the web canvas (L10, L14)

## Goal

Several objects can be selected by Shift-click and rubber band and moved together, and a selected
object can be resized with the engine handles, each as one operation with its inverse, like the
playground and the live demo's selection frame.

**Why:** owner decision 2026-10-29 (close the stage-7 gaps first): selecting and resizing are part
of the demo's canvas feel and of the L10/L14 work orders the app does not wire yet.

**Satisfies:** D12

## Scope

- `apps/web/` selection (L10): Shift-click toggles, rubber band on empty canvas selects by the engine
  rule, the selection frame from the engine chrome; group drag through the P6-17 pointer layer as
  one group operation; L12 keyboard and context menu act on the whole selection (delete, duplicate
  where P6-05 supports it; record any remaining multi-select gap).
- `apps/web/` resize (L14): engine handles on the selected object, minimum sizes (notes, blocks,
  zones incl. member extent + 16 px), one resize operation on release, cancel with `Escape`.
- Realtime: a remote delete of a selected object shrinks the selection instead of throwing.
- Tests: pure tests for selection set changes and resize mapping; e2e for rubber band + group drag,
  resize, undo of both.
- `.changes/P6-18-<short-name>.md` (area `web`, kind `minor`).

## Out of scope

- Zones (P6-19, P6-20), blocks (P6-21), touch, edges.

## Acceptance

A1 WHEN two objects are selected by rubber band and dragged, THEN one group operation with its
inverse is committed and one undo restores both.
A2 WHEN an object is resized, THEN it respects the minimum size, one resize operation is committed,
`Escape` mid-resize leaves it unchanged, and one undo reverts it.
A3 WHEN the task is done, THEN `board-check`, `boundaries`, `unit`, `typecheck`, `design-check`,
`language-check` and `e2e` exit 0 with records and the change entry exists.

## Specifications

- Extend the P6-17 pointer layer; no second pointer handler on the canvas.
- Selection state lives in one place and survives remote updates by id.

## Pitfalls

- Rubber band and pan both start on empty canvas; the active tool decides, never both.
- Resizing a zone below its member extent must be refused by the engine guard, not clipped in the
  app.
