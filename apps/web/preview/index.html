01 — Interactive demo

Live connection demo

Two note cards and one connection. Drag a card with mouse, pen or finger — the whole card is the handle — or focus a card and use the arrow keys (16 px per step, Home resets both). interactive demo — not the engine; no data, no server.

A click without movement (under 4 px) selects the card but does not move it. The four anchor points at the card's side midpoints are invisible geometry; the edge is a curve that snaps between the nearest pair. The zoom pill at the bottom left is preview-only (50 % to 150 %); the product zoom control will use ui-kit icons later.

02 — Colour

Colour tokens

Every swatch reads a generated custom property from the design tokens. Translucent tokens are shown over --card so their effect is visible. No raw colour values appear in this preview.

06 — States

Component states

Every interactive element has rest, hover, pressed, keyboard focus and disabled; cards and blocks also have selected. The samples below show each state side by side; the buttons are real buttons, so native hover, press and focus work too.

Focus is a 2 px --accent outline with 2 px offset; pressed adds scale(0.97); disabled is opacity 0.4 without hover.

This is a static design preview, not the product. It has no engine, no data, no server and no build step; it exists so the design system can be reviewed between milestones. The connection demo is a pointer-event sketch, not the engine.

Colour, spacing, radius, typography, motion, shadow and layer values come only from packages/ui-kit/tokens.css; icons come from packages/ui-kit/icons/. Both are linked relatively and served from the repository root.
